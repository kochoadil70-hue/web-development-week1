Personal Budget & Expense Tracker

This is the first piece of a project you'll be building all the way through Week 8 a fully working Personal Budget & Expense Tracker, the kind of project that can genuinely go into a developer portfolio.

Each week from here on, you'll add a new layer of skill to this exact same project, so what you build today is the literal foundation everything else sits on top of. Don't worry about it looking polished yet that comes later. Right now, the only goal is getting the right HTML structure in place, and practicing the CSS selectors and DevTools skills from this week's lessons.

Treat this like real developer work: build one section at a time, save often, and open it in your browser as you go to check it actually looks right don't write the whole file blind and check it only at the end.

Filename: index.html, style.cssYou're building the very first version of a Budget Tracker website. At this stage, it won't calculate anything or respond to clicks it's purely the visual skeleton, built with plain HTML and a little CSS.

Part 1 - Page structure

Create an index.html file.
Add a main heading at the top of the page that says something like "My Budget Tracker."
Below that, add a short subheading or paragraph describing what the site will do (for example: "Track your income and expenses in one place.")

Part 2 - The "Add Expense" section

Create a 'Add Expense' section on the page (you can use a <div> or <section> tag) for adding a new expense.
Inside it, add input fields for: the expense name, the amount, and the category. You don't need a working form yet just the visual input elements sitting on the page is enough for this week.

Part 3 - The "Your Expenses" placeholder

Below the 'Add Expense' section, create another section with a heading like "Your Expenses." For now, just add some placeholder text inside it, like "No expenses yet" this is where your actual expense list will eventually be displayed, starting from Week 2.

Part 4 - Basic styling with CSS selectors

Create a separate style.css file, and link it to your HTML.
Using the CSS selectors you learned this week (element selectors, class selectors, ID selectors), style your heading, your input section, and your placeholder section so they're visually distinct from each other even something simple like different background colors or spacing is enough at this stage.

Part 5 - Explore with DevTools

Open your page in the browser, right-click anywhere on it, and click Inspect.
Practice selecting different elements in the Elements panel, and try temporarily changing one CSS value live in DevTools (like a color or font size) just to see how it works. This won't save permanently it's just practice for using your browser as a development tool, which you'll rely on constantly going forward.

What you're being assessed on: whether your HTML uses sensible structure (headings, sections, inputs in the right places), whether your CSS selectors are correctly targeting the right elements, and whether your file is organized cleanly with HTML and CSS properly linked together.
